SECTION 03 · OS
3. 最低限おさえておきたいオペレーティングシステム
デバイスを動かす土台のソフトウェア。
OSは、デバイス全体を動かし、アプリや画面を表示するための土台となるシステムです。用途に応じて、大きく3つのカテゴリに分けて理解しましょう。
CATEGORY 01
パソコン向け
Windows Microsoft
世界シェア約60〜70%。企業・行政・家庭のデファクト。
macOS Apple
デザイン・クリエイティブ・プログラマーに根強い人気。
ChromeOS Google
Web特化の軽量OS。教育・ビジネスで導入が急増。
CATEGORY 02
モバイル向け
iOS / iPadOS Apple
iPhone/iPad専用。高セキュリティと直感的操作。
Android Google
世界シェア約7割。多メーカー採用・高いカスタマイズ性。
MOBILE OS SHARE
70% Android世界シェア（約）
CATEGORY 03
サーバー・専門職向け
Linux OSS
世界中のWebサーバー・クラウド環境の主流。
Ubuntu、Red Hatなど。
Windows Server Microsoft
社内ネットワーク／Windows連携システム構築用。

Linuxは必携のOSです。
