SECTION 05 · SECURITY
5-2. セキュリティ意識
情報を守る、3つの防衛線。
LAYER 01 · 認証・更新
強いパスワード ＋ 二段階認証 ＋ 常に最新版
英数字・記号を混在させ、使い回しは避ける。OS・アプリは常に最新にアップデート。
LAYER 02 · ネットワーク
怪しいリンクは開かない ＋ 公共Wi-Fiに注意
http と https（暗号化）の違いを理解。シークレットモードも活用。
LAYER 03 · やってはいけないこと
脱・PPAP
パスワード付きZIPファイルをメール添付し、そのパスワードを別メールで送る方式（PPAP）は
セキュリティ上のリスクがあるため使用しない。
