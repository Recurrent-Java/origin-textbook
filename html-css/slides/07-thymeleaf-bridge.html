Java（Spring Boot）へ繋げる「属性」の理解
HTML の “属性” を理解すると、Thymeleaf の世界が一気に読み解ける。
th:field ／ th:action は HTML 属性の仕組みを “拡張” したものにすぎない。
HTML  ・  属性の正体
属性 (attribute) は “タグに付ける追加情報”。
id  /  class
CSS や JavaScript からの “識別子”。
name  /  value
サーバーに送る “キーと値” のペア。
<input type="text"
       name="username"
       value="taro">
REQUEST PAYLOAD  ・  name=username がキーになる
username = taro
password = ●●●●●●●●
comment  = よろしくお願いします
HTML の name 属性 → そのまま Java Form クラスのフィールド名 と一致
JAVA  ・  Spring Controller
Form クラスのフィールド名が
そのまま “送られてくるキー” と一致する。
// UserForm.java
public class UserForm {
  private String username; // name と一致
  private String password;
  private String comment;
}
@PostMapping("/users/save")
public String save(@ModelAttribute UserForm f) {
  // f.username / f.password で受け取れる
}
Spring が name → フィールド を自動対応してくれる。
THYMELEAF BONUS
<input th:field="*{username}">
→ id / name / value を一括生成
ポイント  ・  HTML の属性 が分かれば、Thymeleaf は怖くない。th:xxx は属性の “拡張版” にすぎない。
