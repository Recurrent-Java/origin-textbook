<table>  +  行ごとに <tr> / <td>
タグ 4 種類  ・  これが書ければ一覧 OK
<table> <tr> <th> <td>
DB 検索結果や一覧画面の表示に必須。th は見出しセル、td はデータセル。
<ul> <li>
エラーメッセージや箇条書き。ul = 順序なしリスト、ol は順序あり。
<a>
画面遷移・処理の呼び出し。サーバー側の GET 系エンドポイントを href に書く。
<a href="/users/2">詳細を見る</a>
<div>  /  <span>
div = ブロック要素（行を占有）／ span = インライン要素（文中の一部）。要素を“まとめる箱”。
ポイント  ・  一覧は table、遷移は a、まとめたい範囲は div / span。これだけで SPA 以外の業務画面の 8 割が書ける。
