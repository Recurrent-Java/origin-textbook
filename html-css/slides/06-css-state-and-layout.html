display: 3 兄弟  ・  ブロック / インライン / 消す
display: block
行を占有。<div>, <p> はこれ。
inline-block
行の中で、幅と高さを持つ。ボタンや入力欄の横並び用。
display: none
要素を消す。JS や条件分岐（Spring の th:if）で大活躍。
ポイント  ・  color / border で “状態を表現”、  display: flex; gap で “揃える”。この 4 つで業務画面の見た目は十分。
