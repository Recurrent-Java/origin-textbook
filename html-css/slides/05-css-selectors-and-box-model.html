スタイルの基本ルールと 余白の概念
CSS の 9 割は「どの要素に（セレクタ）」「どんな余白を（ボックスモデル）」決める仕事。ここを制する。
1. セレクタ  ・  “誰を” 装飾するか
CSS FILE  ・  style.css
/* クラスで指定する */
.btn   { padding: 10px;
        background: #1B5E3F; }
.error { color: #B04830;
        border: 1px solid #B04830; }
使う 3 種類
.xxx
クラス指定
最もよく使う
#xxx
ID 指定
1 ページに 1 個
tag
タグ指定
table, p…
クラス .btn を覚えておけば、業務画面の 8 割はカバーできる。
2. ボックスモデル  ・  “余白の 4 層構造”
margin  ・  外の余白（他の要素との間隔）
border  ・  枠線
padding  ・  内の余白（枠線とテキストの間隔）
content  ・  内容
← margin
他の要素との距離
← border
枠線（必須要素）
← padding
内側の余白
LAYOUT-KILLER SPELL  ・  サイズ計算のズレを防ぐ
* { box-sizing: border-box; }   /* ← まず書く。おまじない。 */
ポイント  ・  余白を制する者がレイアウトを制する。 margin = 外 ／ padding = 内 ／ border-box = 計算ズレ防止。
