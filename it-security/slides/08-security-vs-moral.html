07 — MORAL BASICS
セキュリティ（技術）とモラル（マナー）の違い
両方あって初めて安全。「建物の鍵」と「住人のマナー」の関係で考えると腑に落ちます
🔒
SECURITY
情報セキュリティ
＝ ハード面の対策（システム・技術）
「システムやデータをどう 守るか」
  • ツール／技術：ファイアウォール、暗号化、アクセス制御
  • 担当：IT部門・情シス・セキュリティベンダー
  • やってくるモノ：ウイルス、不正アクセス、自然災害
🤝
MORAL
情報モラル
＝ ソフト面の対策（人の意識・判断）
「得た情報をどう 正しく扱うか」
  • 基準：社内規程、法律、倫理観、世間一般の良識
  • 担当：すべての従業員・社会人ひとりひとり
  • やってくるモノ：うっかりミス、不用意な発言、知識不足
⚠️
モラル欠如 → SNS 炎上 ／ 信頼失墜 ／ 法的責任。 最新技術でも人の判断ミスは止められません。
