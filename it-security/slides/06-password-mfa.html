05 — DEFENSE ①
今日からできるアカウント保護
「弱いパスワード＋使い回し」は最も多い漏洩パターン。今日から3つだけ徹底しましょう
× 弱い
避けたい例
taro1234 / password
  • 短い（8文字未満）・名前や誕生日を含む
  • 英数字のみ・同じ文字の繰り返し
  • 複数サービスで同じPWを使い回す
✓ 強い
作るべき例
Vg#7-bK2!mP9xQzL
  • 12文字以上・大小英字＋数字＋記号
  • 単語や意味を持たないランダム文字列
  • サービスごとに別のパスワード
🛡️ 2段階認証（多要素認証）のしくみ
1
ID と パスワード を入力
従来のログイン（知識要素）
2
スマホに通知 or ワンタイムコード
第二要素（所持要素／生体要素）で確認
3
ログイン完了
パスワード漏洩時も、ここでブロックできる
🔐
強力なパスワード作成
12文字以上、4種（大文字／小文字／数字／記号）混合。意味のある単語は使わない。
🚫
使い回し禁止
1サービスの漏洩が全アカウントに波及。パスワード管理ツールの活用が効果的。
📱
2段階認証の有効化
主要なメール・SNS・銀行・クラウドは原則ON。SMSよりアプリ認証推奨。
