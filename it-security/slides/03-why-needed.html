02 — BACKGROUND
デジタル社会の便利さと
裏に潜むリスク
スマホやPCの普及で便利になった一方、誰もが「被害者」にも「加害者」にもなります
⚠ THE KEY MESSAGE
IT活用は 「攻め（便利さの享受）」 と 「守り（被害／加害の回避）」 の両輪で考える時代へ。
VS
BENEFIT
便利さの享受
  • 場所を問わない仕事・買い物・連絡
  • クラウドでデータ共有が瞬時に
  • AIや自動化で作業効率が大幅UP
RISK
潜むリスク
  • 個人情報・機密データの漏洩
  • 金銭被害（フィッシング、詐欺）
  • SNS炎上や著作権トラブル
🔑 2つのキーワード
セキュリティ と モラル
情報セキュリティ
= 大切なデータやシステムを「守る」技術と対策
情報モラル
= ネット社会で他人に迷惑をかけない「倫理・マナー」
