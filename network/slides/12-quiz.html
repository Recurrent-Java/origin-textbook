QUESTION 01
社内でPCとプリンタをつなぐネットワークは、次のうちどれ？
Ⓐ　WAN　　Ⓑ　LAN　　Ⓒ　DNS　　Ⓓ　MAC
💡 ホバー / タップで解答
ANSWER
Ⓑ LAN（Local Area Network）
オフィスや家庭など限られた範囲のネットワーク。広域を指すWANとは範囲が違います。
QUESTION 02
「機器に焼き込まれている」変わらない住所はどっち？
Ⓐ　IPアドレス
Ⓑ　MACアドレス
💡 ホバー / タップで解答
ANSWER
Ⓑ MACアドレス
MACはNICに固有の物理アドレス。IPはネットワークごとに変わる論理アドレスです。
QUESTION 03
Wi-Fi接続時にIPを自動で配ってくれる仕組みは？
Ⓐ　DNS　　Ⓑ　DHCP　　Ⓒ　WPA2　　Ⓓ　SSID
💡 ホバー / タップで解答
ANSWER
Ⓑ DHCP
Dynamic Host Configuration Protocol。IP・DNS・ゲートウェイなどを自動で配布します。
QUESTION 04
ネットが繋がらない時、まず打つコマンドは？
Ⓐ　format　　Ⓑ　shutdown
Ⓒ　ipconfig / ping　　Ⓓ　cd
💡 ホバー / タップで解答
ANSWER
Ⓒ ipconfig / ping
ipconfigで自分のIPが取れているか、pingで相手まで届くかを確認します。
