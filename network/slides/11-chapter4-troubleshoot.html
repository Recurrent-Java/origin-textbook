CHAPTER 04 ／ トラブル対応とセキュリティ

「つながらない！」を 切り分ける

パニックにならず、順番に確認していけば原因の8割は見つかります。
🩺 トラブル切り分けフロー
「近い場所」から順番に確認するのがコツ
01
ケーブル・Wi-Fi 接続の確認
LANケーブルは差さっているか？ Wi-FiのSSIDは合っているか？
→ 意外と多いのが「機内モードON」「ケーブル抜け」
02
IPアドレスの取得状態を確認
ipconfig でIPが取れているか確認
→ 169.254.x.x ならDHCP失敗、0.0.0.0 なら物理層NG
03
機器の再起動
PC → ルーター → ONU の順で電源OFF/ON
→ 「再起動で直る」は万能薬。ただし業務時間帯は要注意
Command Prompt — ping / ipconfig 実演
# 自分のIPアドレスや設定を確認
C:\Users\you> ipconfig

Reply from 142.250.196.174: bytes=32 time=7ms TTL=118
