CHAPTER 03 ／ 構築ステップ

ネットワークを「作る」— 3ステップ

「IP割当」→「SSID設定」→「セキュリティ」の順で組み上げます。
01
IPアドレスの割り当て
🖊️ 静的 (スタティック)
手動で1台1台設定する方式
→ サーバー・プリンタなど固定したい機器向け
🎫 動的 (ダイナミック)
DHCPで自動配布される方式
→ PC・スマホなど台数の多い端末向け
02
SSID と 無線LAN 設定
📶 Wi-Fi ネットワーク
✓ Office-Network-5G
接続済み・保護
🔒
Office-Guest
🔒
Meeting-Room-A
🔒
SSID（Service Set Identifier）
= Wi-Fi の識別名。ここに表示される名前です。
03
セキュリティ設定
🔐 WPA2 / WPA3 を使う
Wi-Fi Protected Access — 強力な暗号化方式
やってはいけないこと
✕　初期パスワードのまま使う
✕　誰でも読める場所にPWを貼る
✕　古いWEP方式を選ぶ

やるべきこと
✓　英数記号12文字以上のPW
✓　管理画面のPWも変更
✓　定期的にファーム更新
✋
やってみよう —— 自分のWi-Fi環境を確認
① スマホのWi-Fi設定を開く　② 接続中のSSID名をメモ　③「詳細」または「情報」をタップしてセキュリティ方式（WPA2/WPA3）を確認
💡 「動かせば終わり」ではなく「安全に動かす」までがネットワーク構築です。
